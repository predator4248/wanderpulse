# 🌴 WanderPulse Bali — 3D Interactive Tourism Platform

A modern, high-performance 3D WebGL Bali tourism and transit experience built with **Node.js, Express, Three.js, and Vanilla CSS**.

![Tanah Lot Sunset](/images/attractions/tanah-lot/main.jpg)

---

## ✨ Features

- **Genuine Real-World Photography**: 30 authentic, high-definition photographs matching Google Maps & Google Images across all 8 flagship Bali attractions.
- **Official Google Maps Naming Parity**: Dual English and Balinese/Indonesian naming standards (e.g. *Tanah Lot Temple (Pura Tanah Lot)*).
- **Interactive 3D WebGL Island Map**: Real-time Mercator-to-3D projection of Bali topography with interactive hotspot beacons derived from verified GPS coordinates.
- **360° Spherical VR Panoramas**: Immersive 360° equirectangular viewpoints with dynamic sunflare shaders, ocean caustics, and gyro-assisted controls.
- **Geoapify Places API v2 & High-Precision Bali GIS**: Turn-by-turn routing, copyable GPS coordinates, Plus Codes, and Haversine distance calculations.
- **Multimodal Transit Hub**: Real-time flight calculators, Trans-Java executive train + ferry overland routes, and scooter/car rental reservations.
- **Real-Time Currency Engine**: Live conversions across USD, EUR, GBP, AUD, INR, and IDR.

